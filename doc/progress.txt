## Codebase Patterns
- 表情包爬取用 agent-browser + Giphy（国内直连被墙）
- BGM 下载用 Mixkit preview MP3 + Referer 头
- 用 python3.12 运行爬取脚本（python3.11 缺依赖）
- base64 中转 GIF 限制 3MB 以内
- GitHub API (api.github.com) 从国内可以访问，git clone 不行
- SQLite 数据库路径：/root/dreamX/doc/crawler/media_library.db
- 素材路径：表情包 /root/dreamX/doc/memes/，BGM /root/dreamX/doc/bgm/
